# HostLens Prototype

Streamlit app powered by Claude API. Loads a host from the target segment and generates AI-powered recommendations.

## Live demo
https://airbnb-nyc-appuct-analytics-project-qkl8xdb4vwltgjrb2k8ghd.streamlit.app/

## Run locally

1. Install requirements: `pip install -r requirements.txt`
2. Add your Claude API key to `.env`: `ANTHROPIC_API_KEY=sk-ant-...`
3. Run: `streamlit run app.py`
